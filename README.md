# HTML Deepest Text Analyzer

Programa em Java que recebe uma URL como argumento e retorna o trecho de texto que está no **nível mais profundo** da estrutura HTML da página.

---

## 📌 Objetivo
Dado o conteúdo HTML de uma página, o programa identifica qual linha de texto está mais profundamente aninhada dentro das tags HTML e a imprime no console.

Se houver mais de um texto no nível máximo de profundidade, o primeiro encontrado é retornado.

---

## 📥 Entrada
Uma URL válida passada como argumento de linha de comando:

```bash
java HtmlAnalyzer https://exemplo.com/pagina.html
